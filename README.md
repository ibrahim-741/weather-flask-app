# 🌤️ Weather Checker

A simple Flask web app that fetches real-time weather data for any city using the OpenWeatherMap API.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Displays temperature
- 🤗 Displays feels-like temperature
- 💧 Displays humidity
- 💨 Displays wind speed
- 🌤️ Displays weather condition
- 🚨 Graceful error handling for invalid cities
- 🌐 Handles network/API failures
- 📱 Clean and responsive UI
- 🔐 Secure API key handling using environment variables
